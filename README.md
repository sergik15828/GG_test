# Разбор — работа над ошибками для Digital SAT

Прототип модуля для SAT Portal. Превращает ошибку студента в разобранный урок,
а не в «а, понятно» на две секунды.

**Живая версия: https://sergik15828.github.io/GG_test/**

## Проблема

Студент решает вопросы, ошибается, смотрит правильный ответ, кивает — и через неделю
ошибается там же. Причина в том, что разбирают **правильный ответ**, а надо разбирать
**свою ошибку**: почему притянул именно этот неверный вариант и что это говорит о пробеле.

На SAT Portal уже есть практика, таймер, ревью и аналитика. Чего нет ни там, ни у
большинства платформ подготовки — момента, где студент обязан назвать причину своей
ошибки, и механизма, который вернёт этот вопрос позже.

## Что делает сервис

1. **Короткий дрилл** — 6 вопросов, микс Reading & Writing и Math, таймер на каждый вопрос.
2. **Разбор на уровне дистракторов** — после ответа видно не только почему верный вариант
   верный, но и почему каждый из трёх неверных выглядел правдоподобно. У каждого вопроса
   есть названная ловушка.
3. **Обязательный тег причины** — ошибся, значит выбери, почему: не знал тему / не понял
   вопрос / повёлся на ловушку / невнимательность / не хватило времени. Пропустить нельзя,
   кнопка «Дальше» заблокирована. Это и есть главная механика.
4. **Отчёт «Где ты теряешь баллы»** — результат сессии в двух срезах: по доменам College Board
   и по причинам ошибок, плюс адресный совет под доминирующую причину.
5. **Колода ошибок** — каждая ошибка становится карточкой с интервальным повторением
   (сегодня → 1 → 3 → 7 дней → «усвоено»). Верный ответ на повторе двигает карточку дальше,
   неверный сбрасывает в начало.

Прогресс сохраняется между визитами.

## Как запустить

**В один шаг: открой `index.html` в браузере** (двойной клик по файлу).

Ни установки, ни сборки, ни сервера, ни ключей — приложение целиком работает
по протоколу `file://`.

Если удобнее через локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Единственный внешний ресурс — шрифт Inter с Google Fonts. Без интернета приложение
работает, но подхватит системный шрифт.

## Стек

Чистые HTML + CSS + JavaScript, без зависимостей и без сборки. Состояние — `localStorage`.

Почему так: проверяющий не должен ничего настраивать. Любой шаг установки — это шанс,
что прототип не запустится. Поэтому никаких ES-модулей (их блокирует CORS на `file://`),
никакого `fetch`, только классические `<script src>`.

## Структура

```
index.html               точка входа, разметка всех экранов
assets/css/style.css     токены дизайн-системы SAT Portal и компоненты
assets/js/data.js        сид-датасет: 12 вопросов, все 8 доменов Digital SAT
assets/js/icons.js       инлайновые SVG-иконки в стиле lucide
assets/js/store.js       localStorage, интервальное повторение, агрегация статистики
assets/js/app.js         экраны, логика дрилла и колоды
PLAN.md                  план работ, обоснование идеи, зафиксированные решения
SUBMISSION.md            сопроводительный текст к сдаче
```

## Датасет

12 вопросов ручной сборки: 6 Reading & Writing и 6 Math, покрывают все восемь доменов
College Board. Тексты вопросов и вариантов — на английском, как на самом экзамене;
все разборы и подписи — на русском.

У каждого варианта ответа написано, почему он верный или в чём именно его ловушка.
Дистракторы не выдуманы, а восстановлены из типичных ошибок: нераспределённый множитель,
сложение последовательных скидок вместо перемножения, координата вершины вместо значения
функции, comma splice, следствие принятое за пример.

Сессия берёт 6 вопросов, отдавая приоритет тем, которые студент ещё не видел.

## Что осознанно не делалось

Аккаунты, бэкенд, полноразмерный экзамен, adaptive-логика второго модуля, экспорт данных.
Это прототип на пару часов: цель — показать механику и попадание в стиль, а не объём фич.
Полный список решений и границ скоупа — в `PLAN.md`.
